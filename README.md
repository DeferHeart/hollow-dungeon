# HOLLOW

Браузерная roguelike-игра в духе The Binding of Isaac с оригинальной простой графикой. JavaScript и Canvas 2D, без зависимостей и сборки.

[Играть онлайн](https://hollow-dungeon.bloomyorbit10.chatgpt.site)

## Запуск

Скачайте репозиторий и откройте `index.html` в современном браузере. Также можно использовать расширение Live Server в VS Code.

## Управление

- WASD — движение.
- Стрелки — стрельба.
- Пробел — рывок.
- P / Escape — пауза.
- На телефоне — экранные кнопки.

## Игровой процесс

Зачищайте комнаты, выбирайте артефакты и проходите через верхнюю дверь. В восьмой комнате вас ждёт босс. Рекорд сохраняется в localStorage браузера.

В игре: 8 комнат, 3 обычных типа врагов, финальный босс, 6 типов усилений, лечение и рывок.

## Исходники

- `index.html` — разметка и интерфейс.
- `style.css` — стили и адаптация для телефона.
- `game.js` — игровая логика, отрисовка и управление.

Для локального запуска сохраняйте все три файла в одной папке и открывайте `index.html`.

## Проверка

Проверены синтаксис JavaScript и основные переходы игровой логики с имитацией DOM/Canvas: старт, стрельба, урон, усиления, переход между комнатами, появление босса и победа. Визуальная проверка в настоящем браузере пока не проводилась.
